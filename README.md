A 4KB Python chess engine: 0x88 board, negamax alpha-beta search with a fixed 50,000-node budget (no clock, fully deterministic), tapered piece-square evaluation, transposition table, killer moves and quiescence search. Built for make.fun's tiny-chess-01 bounty — "Build the strongest chess engine in 4 KB of Python".

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
